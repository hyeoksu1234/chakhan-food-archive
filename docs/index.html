원산지 확인 기준

  1. 상품 단위로 봅니다. 제조사나 판매처에 공개된 원재료표와 해당 용량의 상품정보를 대조합니다.

  3. 근거를 남깁니다. 상품별 확인 날짜와 원문을 볼 수 있습니다. 원료나 포장이 바뀌면 구매 전에 최신 표기를 확인해 주세요.
