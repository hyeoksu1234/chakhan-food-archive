# 착한 음식 아카이브

국산 원재료가 확인된 식품의 상품정보, 출처, 구매처를 함께 보여주는 반응형 정적 사이트입니다. 들기름, 참기름, 고춧가루, 깨·가루, 선물세트와 함께 장류, 간편식, 국수, 간식 등 가공식품을 수록합니다.

## 실행

저장소 루트에서 실행하고 브라우저에서 `http://localhost:8000`을 엽니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory docs
```

GitHub Pages 배포 소스는 기본 브랜치의 `/docs`입니다.

## 상품 수정

상품 목록은 `docs/products.js`에서 관리합니다. 제품명·용량과 원재료별 원산지를 대조한 뒤 근거 문구, 출처 URL, 확인일을 추가합니다. 가공식품의 `kind`에는 식품의 종류를 적고, 공개 자료에 함량이 표시되지 않은 원재료는 함량 칸에 `null`을 입력합니다. 한 판매 페이지에 여러 용량이 있고 원재료 근거가 동일하면 하나의 상품에 함께 표기할 수 있습니다. 세트의 함량은 구성품별 원재료 표시를 따릅니다.

현재 상품 정보는 제조사·판매처 자료로 확인한 기록입니다. 구매처의 최신 옵션과 재고는 해당 페이지에서 확인할 수 있습니다.

쿠팡 파트너스 링크를 추가할 때는 같은 제품과 용량인지 확인한 뒤, 운영 계정에서 발급한 URL을 `purchase` 항목의 `url`에 넣고 `affiliate: "coupang"`을 지정합니다. 이 상품의 상세 상단에 수수료 안내가 표시되며 `source`와 `url`에 저장한 원산지 출처는 그대로 유지됩니다.
